## Ticks without virtuals

{/* TODO. The self-contained C++20 piece, and the most reusable idea here.

      - Tick methods are detected at compile time by concepts. Implement
        PrePhysics and you get a PrePhysics tick; leave it out and nothing is
        registered and nothing is called.
      - Dispatch is type-erased function pointers sorted by tick group, so
        there is no virtual call and no per-object branch on "does this
        override it".
      - Contrast with the usual approach: a virtual with an empty default,
        costing a call per object per frame to do nothing.

    This section could be its own post if it grows. */}
