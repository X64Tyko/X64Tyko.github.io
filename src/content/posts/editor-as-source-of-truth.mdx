## How it works

{/* TODO
      - TNXFUNC() annotations mark functions exposed to the graph, plus the
        lifecycle hooks: PrePhysics, PhysicsStep, PostPhysics, ScalarUpdate,
        OnSpawn, OnDestroy.
      - A dependency-free DLL scans source and parses method bodies into a
        statement IR: If / Return / Assign / Call / Decl / Raw, with nested
        branches.
      - Graph building lives on the editor side; the parser knows nothing about
        ImGui or the engine. Worth saying why that separation earns its keep:
        the same parser can run as a standalone precompiler.
      - The generator panel goes the other way and emits component source, so
        the schema macros are written by the tool rather than by hand. */}
